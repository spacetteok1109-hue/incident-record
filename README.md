# incident-record

이 저장소에는 휴대전화에서 앱처럼 쓰는 웹앱 두 개가 들어 있습니다.

| 앱 | 주소 | 설명 |
| --- | --- | --- |
| **내 할 일 · 캘린더** | `.../incident-record/app/` | 투두 리스트 + 캘린더 + 디데이 (아래 문서) |
| **현장 관리 · 팀원 일당** | `.../incident-record/work/` | 건설 현장의 팀원·현장·출역·일당·가불 관리 → [work/README.md](work/README.md) |

저장소 루트의 `index.html`(사립탐정 사건 기록부)은 그대로 두었습니다.

# 내 할 일 · 캘린더

휴대전화에서 앱처럼 쓰는 **투두 리스트 + 캘린더 + 디데이** 앱입니다.
설치 없이 브라우저로 열고, 홈 화면에 추가하면 주소창 없이 앱처럼 실행됩니다.

**모든 데이터는 이 기기 안에만 저장됩니다.** 서버로 보내는 통신이 아예 없고,
회원가입도 없습니다.

> 앱 파일은 `app/` 폴더에 있습니다.

## 휴대전화에 설치하기

### 1) 주소 준비

이 저장소를 GitHub Pages로 켜면 바로 씁니다.

1. GitHub 저장소 → **Settings** → **Pages**
2. Source: **Deploy from a branch**, Branch: `main` / 폴더 `/ (root)` → Save
3. 잠시 뒤 아래 주소로 접속

```
https://spacetteok1109-hue.github.io/incident-record/app/
```

> 알림과 오프라인 기능은 보안상 **https 주소**에서만 동작합니다.
> GitHub Pages는 https라 그대로 쓰면 됩니다.

### 2) 홈 화면에 추가

**아이폰 (Safari)**
1. 위 주소를 **Safari로** 엽니다. (크롬 말고 Safari여야 알림이 켜집니다)
2. 아래 공유 버튼 <kbd>􀈂</kbd> → **홈 화면에 추가**
3. 홈 화면에 생긴 아이콘으로 실행 → 설정 화면에서 **알림 켜기**

**안드로이드 (Chrome)**
1. 위 주소를 크롬으로 엽니다.
2. 오른쪽 위 ⋮ → **앱 설치** (또는 홈 화면에 추가)
3. 실행한 뒤 알림 허용

## 알림에 대해 알아 두실 점

이 앱은 서버를 쓰지 않기 때문에(그래서 데이터가 밖으로 나가지 않습니다),
알림도 기기 안에서만 처리합니다. 그래서 이렇게 동작합니다.

- **앱이 켜져 있을 때**: 지정한 시각에 정확히 알림이 뜹니다.
- **앱을 닫아 둔 안드로이드/크롬**: 브라우저가 주기적으로 앱을 깨워 확인합니다
  (약 15분 간격). 시각이 몇 분 밀릴 수 있습니다.
- **아이폰**: 홈 화면에 추가해 설치한 뒤에만 알림을 켤 수 있습니다.
  iOS는 닫힌 웹앱을 깨워 주지 않아, 앱을 열었을 때 지난 알림을 모아서 보여 줍니다.

정확한 시각의 백그라운드 알림이 꼭 필요하다면 기기의 기본 캘린더/미리알림 앱과
함께 쓰시는 편이 안전합니다.

## 홈 화면 위젯은 되나요

**네이티브 위젯(달력 내용이 배경화면에 바로 보이는 형태)은 웹앱으로는 만들 수 없습니다.**
iOS 위젯은 WidgetKit(Swift), 안드로이드 위젯은 AppWidgetProvider가 필요해서
앱스토어에 올리는 네이티브 앱이어야 합니다. 브라우저에는 위젯을 만드는 API 자체가 없습니다.

대신 실제로 되는 것:

- **앱 아이콘 배지** — 홈 화면 아이콘 오른쪽 위에 오늘 남은 할 일 개수가 빨간 숫자로 뜹니다.
  안드로이드 크롬, 그리고 iOS 16.4 이상에서 홈 화면에 추가한 경우 동작합니다.
  설정 → 표시 → *홈 화면 아이콘에 개수 표시*에서 끌 수 있습니다.
- **홈 화면 아이콘** — 홈 화면에 추가하면 일반 앱과 똑같이 아이콘으로 자리잡고,
  주소창 없이 전체 화면으로 열립니다.
- **아이폰 단축어 위젯** — 단축어 앱에서 *URL 열기* 동작을 만들고 이름을 붙이면,
  홈 화면 위젯(단축어 위젯)에서 한 번 눌러 앱을 열 수 있습니다.
  내용이 보이지는 않고 바로가기 역할만 합니다.
- **알림** — 정해 둔 시각에 잠금화면으로 알림이 옵니다. 배경화면에 항상 떠 있는 것은 아니지만,
  실제로 챙겨야 할 때 알려 준다는 점에서는 위젯과 목적이 비슷합니다.

## 업데이트가 안 보일 때

앱은 파일을 기기에 저장해 두고 오프라인에서도 열리게 합니다. 그래서 새 기능을
올려도 예전 화면이 잠시 남을 수 있습니다. 보통은 앱을 열면 알아서 새로 불러오지만,
바뀌지 않았다면 **설정 → 앱 → 버전**을 눌러 주세요. 최신 버전을 확인하고 다시 불러옵니다.

그래도 안 되면 앱을 완전히 종료했다가(앱 스위처에서 위로 밀기) 다시 열어 보세요.

## 데이터와 보안

- 할 일·폴더·사진·설정은 브라우저의 **IndexedDB**에 저장되며, 이 기기를 벗어나지 않습니다.
- 네트워크로 나가는 요청은 앱 파일을 처음 내려받을 때뿐입니다. 그 뒤로는 오프라인으로 동작합니다.
- **PIN 잠금**은 PBKDF2(SHA-256, 21만 회) 해시만 저장하며 PIN 자체는 저장하지 않습니다.
  다만 이것은 *다른 사람이 기기를 잠깐 만졌을 때* 내용을 못 보게 하는 잠금이며,
  저장된 데이터 자체를 암호화하지는 않습니다. 기기 전체 암호화(잠금화면 암호)를 함께 켜 두세요.
- **주의**: 브라우저에서 "사이트 데이터 삭제"를 하거나 앱을 삭제하면 데이터도 함께 지워집니다.
  설정 → **백업 파일 내보내기**로 가끔 백업해 두세요.

## 사용법 요약

- 오른쪽 아래 **＋** 버튼: 새 항목. 종류를 `할 일 / 일정 / 디데이` 중에 고릅니다.
- 디데이에서 **기간으로 관리**를 켜면 시작일과 총 일수 칸이 나옵니다.
  - 시작일과 마감일을 넣으면 → 총 며칠인지, 오늘이 몇 일째인지 계산됩니다.
  - 총 일수를 넣거나 `30일` 같은 칩을 누르면 → 마감일이 계산됩니다.
  - 일수는 **시작일을 포함해서** 셉니다. 8월 1일부터 3일이면 8월 3일이 마감입니다.
- 항목을 **탭**하면 수정, **길게 누르면** 삭제.
- 왼쪽 동그라미를 누르면 완료. 반복 항목은 완료하는 순간 다음 날짜로 넘어갑니다.
- 캘린더에서 날짜를 누르고 **＋ 추가**를 누르면 그 날짜로 바로 등록됩니다.
- 폴더 탭에서 폴더를 열고 ＋를 누르면 그 폴더로 등록됩니다.
- 상단 🔍로 제목·메모·체크리스트를 검색합니다.

## 파일 구조

```
app/
├── index.html              앱 화면 (셸)
├── manifest.webmanifest    홈 화면 추가·앱 이름·아이콘 정의
├── sw.js                   서비스 워커: 오프라인 캐시 + 백그라운드 알림 확인
├── css/style.css           모바일 우선 스타일 (다크/라이트, 노치 대응)
├── icons/                  앱 아이콘 (192·512·maskable·apple-touch)
└── js/
    ├── app.js              화면 구성, 탭 이동, 설정, 잠금 화면
    ├── db.js               IndexedDB 저장소 (기기 내부 전용)
    ├── store.js            폴더·항목 도메인 로직, 반복 처리, 백업/복원
    ├── media.js            사진 업로드, 축소·썸네일 생성
    ├── notify.js           알림 권한과 시각 예약
    ├── lock.js             PIN 해시 설정·검증
    ├── editor.js           항목/폴더 편집 시트
    ├── ui.js               토스트, 바텀 시트, 확인창
    ├── icons.js            인라인 SVG 아이콘 (직접 그림)
    └── util.js             날짜·디데이·포맷 유틸리티
```

라이브러리 없이 순수 HTML·CSS·JavaScript(ES 모듈)로만 만들었습니다.

### 아이콘

탭바와 버튼 아이콘은 `app/js/icons.js` 에 직접 그린 인라인 SVG 입니다.
외부 아이콘 파일을 받아오지 않으므로 별도 라이선스나 출처 표기가 필요 없고,
`currentColor` 를 쓰기 때문에 테마 색을 그대로 따라갑니다.
24x24 격자에 선 굵기 1.75, 끝을 둥글게 맞춰 한 세트로 보이게 했습니다.

새 아이콘이 필요하면 `PATHS` 에 항목을 추가하고 `icon('이름')` 으로 쓰면 됩니다.

## 직접 실행해 보기

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/app/ 접속
```

`file://`로 바로 열면 ES 모듈과 서비스 워커가 막히니 위처럼 간단한 서버로 여세요.

### 앱을 저장소 루트 주소로 옮기고 싶다면

`app/` 안의 파일을 루트로 옮기고 기존 `index.html`을 다른 이름
(예: `detective.html`)으로 바꾸면 `.../incident-record/` 주소로 바로 열립니다.
