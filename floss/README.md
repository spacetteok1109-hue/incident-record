# 실 자르기 · 색코드

실 사진에서 **빨간선으로 표시해 둔 실만** 잘라 내고, 순서대로 정렬해서 한 장으로
붙이거나 낱장으로 저장하는 웹앱입니다. 책자(색상표)를 고르면 잘라 낸 실 색에
**가장 가까운 실 번호**를 따로 알려 줍니다.

주소: `https://spacetteok1109-hue.github.io/incident-record/floss/`

사진은 이 기기 밖으로 나가지 않습니다. 서버로 올리는 통신이 없습니다.

### 파일 하나로도 씁니다

`floss/standalone.html` 은 스타일·스크립트·색상표를 전부 안에 넣은 **한 파일짜리 판**입니다.
내려받아 두면 인터넷 없이 그 파일만 열어도 똑같이 돌아갑니다. 원본을 고친 뒤에는
다시 만들어 주세요.

```
node floss/build-standalone.mjs
```

문서 뼈대(`<html>`·`<head>`·`<body>`)를 씌워 주는 곳에 올릴 때는 뼈대를 뺀 판도 만들 수 있습니다.

```
node floss/build-standalone.mjs --artifact 내보낼파일.html
```

## 세 가지 약속

| 원하신 것 | 이 앱이 하는 일 |
| --- | --- |
| **숫자·표시를 말하면 그 실을 찾아 잘라 줄 것** | 번호를 적으면 ① 고른 책자에서 그 번호의 색을 꺼내 사진 속 같은 실을 찾고 ② 책자에 없으면 사진에 적힌 글자를 읽어 그 번호 옆의 실을 잡습니다. 책자는 카드 사진으로 직접 만들 수 있습니다. |
| **실 색이 조금도 바뀌지 않을 것** | 자를 때 크기를 바꾸지 않고 픽셀을 1:1 로 복사하고, 보간·필터·보정을 모두 끄고, 무손실 **PNG** 로만 저장합니다. (JPEG 은 쓰지 않습니다.) |
| **정렬해서 붙이거나, 책자 색코드를 따로 뽑을 것** | 읽는 순서대로 자동 정렬해 한 장으로 이어붙일 수 있고, 색코드는 **사진을 고치지 않고** 목록·라벨·CSV 로만 따로 알려 줍니다. |

### 색이 바뀌지 않는다는 것을 어떻게 확인했나

브라우저에서 실제로 잘라 PNG 로 저장했다가 다시 읽어들여, 원본 픽셀과
한 바이트씩 비교했습니다.

```
비교한 값 136,800개 (190×180 픽셀 × RGBA)
다른 값 0개 · 최대 차이 0
이어붙인 뒤에도 최대 차이 0
```

이어붙일 때도 조각을 늘이거나 줄이지 않고, 글자(번호·색코드)는 조각
**바깥쪽 여백에만** 그리므로 실 픽셀에는 아무것도 덧그리지 않습니다.

## 쓰는 순서

1. **사진** — 실 사진을 고르거나, 끌어다 놓거나, `Ctrl`+`V` 로 붙여넣습니다.
   여러 장을 한꺼번에 넣어도 됩니다.
2. **자르기** — `빨간선 찾기` 를 누르면 빨간 표시가 있는 자리를 잡습니다.
   - **번호 밑에 밑줄**을 그었다면 → 표시한 자리에서 실 쪽으로 **사진 끝까지 세로로 길게** 자릅니다.
     색상표 사진처럼 실타래가 아래로 늘어져 있어도 실이 다 담깁니다.
   - 빨간 **네모·동그라미**로 둘러쌌다면 → 그 **안쪽**을 자릅니다(빨간 선이 섞이지 않습니다).
   - 손으로 잡고 싶으면 `그리기` 로 바꿔 끌어서 상자를 만들고, 모서리를 잡아 크기를 바꿉니다.
3. **조각** — 정렬 순서를 고르고, 책자를 고른 뒤 `색코드 뽑기` 를 누릅니다.
   추천 번호를 누르면 그 번호가 조각 이름이 됩니다.
4. **내보내기** — `이어붙여 한 장 저장` 또는 `조각 낱장 저장`.
   색코드 목록은 글·CSV 로 복사하거나 파일로 저장합니다.

## 색상표(실 카드) 사진은 이렇게 처리합니다

번호가 한 줄로 적혀 있고 그 아래로 실타래가 길게 늘어진 사진이 가장 흔합니다.
빨간 밑줄 하나만 그어 두면 이렇게 잘라 냅니다.

| 단계 | 하는 일 |
| --- | --- |
| 표시 찾기 | 밝고 선명한 빨강만 표시로 봅니다. 분홍·살구·자주 실은 색이 아무리 붉어도 표시로 잡지 않습니다. |
| 실 쪽 정하기 | 표시 위아래(또는 좌우)를 사진 끝까지 훑어, 색이 더 많은 쪽을 실이 있는 쪽으로 봅니다. |
| 세로로 길게 | 표시한 자리에서 그 방향으로 **사진 끝까지** 잘라, 늘어진 실이 중간에서 끊기지 않게 합니다. |
| 여백 다듬기 | 표시와 실 사이에 낀 흰 번호 칸만 걷어 냅니다. 실 끝 쪽은 건드리지 않습니다. |
| 폭 맞추기 | 표시 길이에 `좌우 여유`(기본 30%)를 더해 타래 폭에 맞춥니다. 옆 타래가 딸려 오면 줄여 주세요. |

실 색을 읽을 때는 가닥 사이 그늘과 반들거리는 겉면을 빼고, 눈에 보이는 실 겉면
밝기대만 씁니다. 그늘까지 섞으면 실제보다 어둡게 읽힙니다.

## 알아 두면 좋은 것

- **빨간 실이 사진에 같이 있을 때** — 굵고 꽉 찬 빨강 덩어리는 표시가 아니라 실로 보고,
  실 가닥에서 튀는 붉은 점들도 걸러 냅니다
  (자르기 → `빨간선을 어떻게 읽을지 조절하기` 에서 끌 수 있습니다).
  굵은 붓으로 그은 표시가 무시되면 이 항목을 꺼 주세요.
- **DMC 가 아닌 책자를 쓸 때** — 사진 속 번호가 DMC 번호가 아니라면, DMC 추천값은
  "가장 비슷한 다른 회사 색"일 뿐입니다. ΔE 가 6을 넘으면 그렇다고 알려 줍니다.
  쓰시는 책자를 CSV 로 넣으면 그 책자 번호로 바로 나옵니다.
- **빨간선이 안 잡힐 때** — `빨강 민감도`를 낮추면 옅은 빨강까지 잡습니다.
  선이 끊겨 있으면 `끊긴 선 잇기`를 올려 주세요.
- **번호 읽기(OCR)** — 사진 속 글자를 읽는 기능은 처음 한 번 인터넷이 필요합니다.
  못 받아 오면 색으로 찾는 방법으로 넘어가고, 번호는 조각 목록에서 손으로 적어도 됩니다.
- **ΔE** — 두 색의 차이입니다. `2` 아래면 눈으로는 거의 구분되지 않고,
  `6` 을 넘으면 확실히 다른 색입니다. 사진 조명에 따라 값이 달라지므로,
  실제 실과 화면을 함께 보고 고르시는 편이 정확합니다.

## 책자(색상표) — 번호만 적으면 실이 나오게

**책자** 화면에서 카드 사진으로 내 책자를 채워 두면, 그다음부터는 번호만 적어도
그 실이 나옵니다. 앨리스(亚丽丝)·은행나무(银杏)처럼 DMC 가 아닌 책자도 그대로 씁니다.

### 만드는 순서

1. **새 책자 만들기** — 이름을 적습니다 (예: `앨리스(亚丽丝)`).
2. 카드 사진을 불러오고 **타래 찾기** — 사진 속 타래를 전부 찾아 색을 읽습니다.
3. **번호 한 번에 붙여넣기** 칸에 카드에 적힌 번호를 왼쪽부터 차례로 적습니다.
   `167 1811 1790 1809 …` 처럼 띄어쓰기·쉼표 아무거나 됩니다.
   개수가 맞는지 바로 알려 줍니다.
4. **책자에 넣기** — 사진 한 장마다 반복하면 책자가 쌓입니다. 같은 번호를 다시
   넣으면 새 값으로 바뀝니다.
5. **CSV 로 내보내기** 로 백업해 두세요. 책자는 이 브라우저 안에만 저장됩니다.

### 쓰는 법

- **책자 → 번호로 실 찾기** 에 `1432` 를 적으면 그 실의 색과 색코드가 나옵니다.
  사진이 열려 있으면 `사진에서 찾기` 로 그 실이 어디 있는지도 잡아 줍니다.
- **자르기 → 번호·표시로 찾기** 도 책자를 먼저 봅니다. 책자에 있는 번호면
  **인터넷 없이 바로** 그 실을 찾습니다. 없을 때만 사진 속 글자를 읽어 봅니다.
- 빨간선으로 표시해 자른 조각은 `색코드 뽑기` 를 누르면 내 책자 번호로 나옵니다.

### 타래를 어떻게 찾나

번호 칸의 **표 세로선**은 간격이 일정합니다. 그 선들을 찾아 가장 잘 들어맞는
격자를 맞추고(최소제곱으로 한 번 더 다듬습니다), 칸마다 아래 실을 한 타래로 봅니다.
숫자 획도 어둡지만 짧아서, **세로로 길게 이어지는 선**만 표 선으로 봅니다.
표가 없는 사진이면 실 색이 바뀌는 자리로 대신 나눕니다.

주신 카드 사진(1080×660)에서는 세로선 9개를 찾아 칸 폭 74px 격자를 맞추고
타래 14개를 잡았습니다. 번호를 붙여 책자에 넣은 뒤, 빨간선으로 표시한 실을
자르면 `1432` 가 ΔE 1.5 로 1순위에 나옵니다 — 사진에 밑줄 쳐 둔 바로 그 번호입니다.

## 색상표 파일로 넣기

이미 갖고 있는 색상표 파일이 있으면 `책자 → 색상표 파일 넣기` 로 바로 넣습니다.

받는 형식 (셋 중 아무거나):

```csv
번호,이름,색상
001,진초록,#174923
002,하늘,#93B4CE
```

```csv
번호,이름,R,G,B
310,Black,0,0,0
890,Pistachio,23,73,35
```

```json
{ "name": "내 책자", "colors": [ { "code": "001", "name": "진초록", "hex": "#174923" } ] }
```

첫 줄이 머리글이어도 알아서 건너뜁니다.

## 만듦새

설치할 것이 없는 순수 웹앱입니다. 빌드 도구도, 서버도 쓰지 않습니다.

| 파일 | 하는 일 |
| --- | --- |
| `js/detect.js` | 빨간 픽셀 찾기 → 끊긴 선 잇기 → 덩어리 나누기 → 표시 모양(테두리·줄·점) 판별 |
| `js/crop.js` | 1:1 잘라내기, 읽는 순서로 정렬, 이어붙이기 |
| `js/sample.js` | 조각에서 실 색 뽑기 (빨간선·종이 여백을 빼고 Lab 공간에서 가장 두꺼운 색 덩어리) |
| `js/color.js` | sRGB↔Lab 변환, CIEDE2000 색 차이 |
| `js/card.js` | 카드 사진에서 타래 전부 찾기 (표 세로선 → 격자 맞추기) |
| `js/palette.js` | 책자 만들기·넣기·내보내기, 가장 가까운 번호 찾기 |
| `js/ocr.js` | (선택) 사진 속 번호 읽기 |
| `data/dmc.json` | DMC 454색 |

색 차이 계산(CIEDE2000)은 Sharma 검증 데이터셋으로 값을 맞춰 두었습니다.

DMC 색값 출처: [sharlagelfand/dmc](https://github.com/sharlagelfand/dmc)
(원본 [adrianj/CrossStitchCreator](https://github.com/adrianj/CrossStitchCreator)).
DMC 사에서 공식으로 낸 값이 아니라 널리 쓰이는 근사값이므로, 참고용으로 봐 주세요.
