# 실 자르기 · 색코드

실 사진에서 **빨간선으로 표시해 둔 실만** 잘라 내고, 순서대로 정렬해서 한 장으로
붙이거나 낱장으로 저장하는 웹앱입니다. 책자(색상표)를 고르면 잘라 낸 실 색에
**가장 가까운 실 번호**를 따로 알려 줍니다.

주소: `https://spacetteok1109-hue.github.io/incident-record/floss/`

사진은 이 기기 밖으로 나가지 않습니다. 서버로 올리는 통신이 없습니다.

---

## 세 가지 약속

| 원하신 것 | 이 앱이 하는 일 |
| --- | --- |
| **숫자·표시를 말하면 그 실을 찾아 잘라 줄 것** | `번호·표시로 찾기` 에 `310` 처럼 적으면 ① 사진 속 글자를 읽어 그 번호 옆의 실을 잡고 ② 이미 빨간선으로 표시해 둔 자리면 그 자리를 쓰고 ③ 글자를 못 읽으면 책자에서 그 번호의 색과 가장 비슷한 조각을 골라 줍니다. |
| **실 색이 조금도 바뀌지 않을 것** | 자를 때 크기를 바꾸지 않고 픽셀을 1:1 로 복사하고, 보간·필터·보정을 모두 끄고, 무손실 **PNG** 로만 저장합니다. (JPEG 은 쓰지 않습니다.) |
| **정렬해서 붙이거나, 책자 색코드를 따로 뽑을 것** | 읽는 순서대로 자동 정렬해 한 장으로 이어붙일 수 있고, 색코드는 **사진을 고치지 않고** 목록·라벨·CSV 로만 따로 알려 줍니다. |

### 색이 바뀌지 않는다는 것을 어떻게 확인했나

브라우저에서 실제로 잘라 PNG 로 저장했다가 다시 읽어들여, 원본 픽셀과
한 바이트씩 비교했습니다.

```
비교한 값 136,800개 (190×180 픽셀 × RGBA)
다른 값 0개 · 최대 차이 0
이어붙인 뒤에도 최대 차이 0
```

이어붙일 때도 조각을 늘이거나 줄이지 않고, 글자(번호·색코드)는 조각
**바깥쪽 여백에만** 그리므로 실 픽셀에는 아무것도 덧그리지 않습니다.

---

## 쓰는 순서

1. **사진** — 실 사진을 고르거나, 끌어다 놓거나, `Ctrl`+`V` 로 붙여넣습니다.
   여러 장을 한꺼번에 넣어도 됩니다.
2. **자르기** — `빨간선 찾기` 를 누르면 빨간 표시가 있는 자리를 잡습니다.
   - 빨간 **네모·동그라미**로 둘러쌌다면 → 그 **안쪽**을 자릅니다(빨간 선이 섞이지 않습니다).
   - 빨간 **밑줄·옆줄**을 그었다면 → 줄 옆에서 **색이 있는 쪽**의 띠를 자릅니다.
   - 빨간 **점·체크**를 찍었다면 → 그 표시 둘레를 자릅니다.
   - 손으로 잡고 싶으면 `그리기` 로 바꿔 끌어서 상자를 만들고, 모서리를 잡아 크기를 바꿉니다.
3. **조각** — 정렬 순서를 고르고, 책자를 고른 뒤 `색코드 뽑기` 를 누릅니다.
   추천 번호를 누르면 그 번호가 조각 이름이 됩니다.
4. **내보내기** — `이어붙여 한 장 저장` 또는 `조각 낱장 저장`.
   색코드 목록은 글·CSV 로 복사하거나 파일로 저장합니다.

## 알아 두면 좋은 것

- **빨간 실이 사진에 같이 있을 때** — 굵은 빨강 덩어리는 표시가 아니라 실로 봅니다
  (자르기 → `빨간선을 어떻게 읽을지 조절하기` 에서 끌 수 있습니다).
  굵은 붓으로 그은 표시가 무시되면 이 항목을 꺼 주세요.
- **빨간선이 안 잡힐 때** — `빨강 민감도`를 낮추면 옅은 빨강까지 잡습니다.
  선이 끊겨 있으면 `끊긴 선 잇기`를 올려 주세요.
- **번호 읽기(OCR)** — 사진 속 글자를 읽는 기능은 처음 한 번 인터넷이 필요합니다.
  못 받아 오면 색으로 찾는 방법으로 넘어가고, 번호는 조각 목록에서 손으로 적어도 됩니다.
- **ΔE** — 두 색의 차이입니다. `2` 아래면 눈으로는 거의 구분되지 않고,
  `6` 을 넘으면 확실히 다른 색입니다. 사진 조명에 따라 값이 달라지므로,
  실제 실과 화면을 함께 보고 고르시는 편이 정확합니다.

## 책자(색상표)

- 기본으로 **DMC 25번 자수실 454색**이 들어 있습니다.
- 다른 책자는 `조각 → 색상표 넣기` 로 파일을 넣으면 됩니다. 넣은 색상표는
  이 브라우저 안에만 저장됩니다.

받는 형식 (셋 중 아무거나):

```csv
번호,이름,색상
001,진초록,#174923
002,하늘,#93B4CE
```

```csv
번호,이름,R,G,B
310,Black,0,0,0
890,Pistachio,23,73,35
```

```json
{ "name": "내 책자", "colors": [ { "code": "001", "name": "진초록", "hex": "#174923" } ] }
```

첫 줄이 머리글이어도 알아서 건너뜁니다.

## 만듦새

설치할 것이 없는 순수 웹앱입니다. 빌드 도구도, 서버도 쓰지 않습니다.

| 파일 | 하는 일 |
| --- | --- |
| `js/detect.js` | 빨간 픽셀 찾기 → 끊긴 선 잇기 → 덩어리 나누기 → 표시 모양(테두리·줄·점) 판별 |
| `js/crop.js` | 1:1 잘라내기, 읽는 순서로 정렬, 이어붙이기 |
| `js/sample.js` | 조각에서 실 색 뽑기 (빨간선·종이 여백을 빼고 Lab 공간에서 가장 두꺼운 색 덩어리) |
| `js/color.js` | sRGB↔Lab 변환, CIEDE2000 색 차이 |
| `js/palette.js` | 책자 불러오기·가져오기, 가장 가까운 번호 찾기 |
| `js/ocr.js` | (선택) 사진 속 번호 읽기 |
| `data/dmc.json` | DMC 454색 |

색 차이 계산(CIEDE2000)은 Sharma 검증 데이터셋으로 값을 맞춰 두었습니다.

DMC 색값 출처: [sharlagelfand/dmc](https://github.com/sharlagelfand/dmc)
(원본 [adrianj/CrossStitchCreator](https://github.com/adrianj/CrossStitchCreator)).
DMC 사에서 공식으로 낸 값이 아니라 널리 쓰이는 근사값이므로, 참고용으로 봐 주세요.
