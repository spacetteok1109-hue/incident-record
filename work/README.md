# 현장 관리 · 팀원 일당

건설 현장 팀장이 **팀원 · 현장 · 출역(누가 어디 나갔는지) · 일당 · 가불**을
휴대전화에서 관리하는 앱입니다. 설치 없이 브라우저로 열고, 홈 화면에 추가하면
주소창 없이 앱처럼 실행됩니다.

**기본적으로 모든 데이터는 이 기기 안에만 저장됩니다.**
구글 백업을 직접 켰을 때만, 로그인한 구글 계정의 스프레드시트로 올라갑니다.

주소: `https://spacetteok1109-hue.github.io/incident-record/work/`

## 금액이 어떻게 계산되나요

```
출역 1건 지급액 = 일당 × 공수 + (자기 차로 갔다면) 차량 수당
월 실지급액     = 그 달 지급액 합계 − 그 달 가불 + 그 달 상환
```

- **일당**은 팀원에게 등록해 둔 금액이 기본으로 들어가고, 배정할 때 그 날만 다르게 고칠 수 있습니다.
  현장 단가는 배정 화면에 참고로 같이 보여 줍니다.
- **공수**는 하루 일한 양입니다. 반나절이면 `0.5공수`, 잔업이면 `1.5공수`처럼 고릅니다. 기본은 1입니다.
- **자차**는 팀원에게 "자차 있음"을 켜 두면 배정할 때 자동으로 체크됩니다.
  차량 수당을 0으로 두면 금액 없이 "누구 차로 갔는지"만 기록됩니다.
- **가불**은 미리 준 돈입니다. 그 달 지급액에서 빠지고, 아직 정산되지 않은 금액은
  팀원 카드에 `가불 30만`처럼 빨갛게 표시됩니다.
  현금으로 돌려받았다면 **상환**으로 기록하면 잔액이 줄어듭니다.

> 실지급액이 마이너스로 나오면, 그 달 번 돈보다 미리 가져간 돈이 많다는 뜻입니다.

## 구글 스프레드시트 백업 켜기

이 앱은 서버가 없습니다. 그래서 백업도 **휴대전화가 구글에 직접 로그인해서**
올리는 방식이고, 그러려면 구글에서 "이 앱"을 한 번 등록해 줘야 합니다.
**한 번만 하면 됩니다.** 컴퓨터에서 하는 편이 편합니다.

### 1) 구글 클라우드에서 앱 등록하기

1. <https://console.cloud.google.com/> 에 백업받을 구글 계정으로 로그인합니다.
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름은 아무거나 (예: `현장관리`) → 만들기.
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `Google Sheets API` 검색 → **사용** 을 누릅니다.
4. **API 및 서비스 → OAuth 동의 화면**
   - User Type: **외부** → 만들기
   - 앱 이름: `현장관리`, 사용자 지원 이메일과 개발자 연락처에 본인 지메일 주소
   - 범위(scope) 단계는 아무것도 추가하지 않고 그냥 넘어갑니다.
   - **테스트 사용자** 단계에서 **본인 지메일 주소를 추가**합니다. (이게 빠지면 로그인이 막힙니다)
5. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 자바스크립트 원본**에 아래를 추가합니다.
     ```
     https://spacetteok1109-hue.github.io
     ```
   - 리디렉션 URI는 비워 둡니다.
   - 만들기를 누르면 나오는 **클라이언트 ID**(`....apps.googleusercontent.com`)를 복사합니다.

### 2) 앱에 붙여넣기

1. 앱 → **설정 → 구글 클라이언트 ID → 입력** 에 붙여넣고 저장합니다.
2. **구글 계정 → 연결** 을 누르면 구글 로그인 창이 뜹니다.
   - "Google에서 확인하지 않은 앱입니다" 경고가 나오면 **고급 → (앱 이름)(으)로 이동** 을 누릅니다.
     본인이 만든 앱이라 그렇습니다.
   - 권한 화면에서 허용합니다.
3. **자동 백업**을 켭니다. 이제 내용이 바뀌면 잠시 뒤 알아서 올라갑니다.
4. **지금 백업하기**를 한 번 눌러 보면 스프레드시트가 만들어집니다.
   **스프레드시트 열기**로 확인하세요.

### 백업되는 내용

구글 드라이브에 `현장 관리 백업` 이라는 파일 하나가 생기고, 그 안에 시트 5장이 들어갑니다.

| 시트 | 내용 |
| --- | --- |
| 팀원 | 이름, 생년, 연락처, 일당, 자차, 차량수당, 은행, 계좌번호, 예금주, 가불잔액, 상태, 메모 |
| 현장 | 현장명, 주소, 단가, 업체, 연락처, 시작일, 종료일, 상태, 메모 |
| 출역 | 날짜, 요일, 현장, 팀원, 일당, 공수, 일당합계, 자차, 차량수당, 지급액, 지급완료, 메모 |
| 가불 | 날짜, 팀원, 구분(가불/상환), 금액, 메모 |
| 월정산 | 월별·팀원별 출역일수, 공수, 일당합계, 차량수당, 총액, 가불, 상환, 실지급, 가불잔액 |

금액은 숫자로 들어가므로 스프레드시트에서 바로 더하거나 필터할 수 있습니다.

### 알아 두실 점

- 백업은 **앱 화면을 열어 둔 동안에만** 올라갑니다. 서버가 없어서, 앱이 닫혀 있으면
  백업도 쉽니다. 앱을 열면 다시 한 번 올립니다.
- 백업은 **덮어쓰기**입니다. 스프레드시트에 직접 적어 넣은 내용은 다음 백업 때 지워집니다.
  메모가 필요하면 앱 안의 메모 칸에 적으세요.
- 앱에 주는 권한은 `drive.file` 하나뿐입니다. **이 앱이 만든 파일 한 개**에만 손댈 수 있고,
  드라이브의 다른 파일은 읽지도 쓰지도 못합니다.
- 스프레드시트를 실수로 지웠다면, 다음 백업 때 새로 만듭니다.
  일부러 새 파일로 바꾸고 싶으면 설정의 **새 파일로 다시 만들기**를 누르세요.
- 구글 백업과 별개로, 설정 → **백업 파일 내보내기**로 JSON 파일을 따로 보관해 두시길 권합니다.

## 데이터와 보안

- 팀원·현장·출역·가불은 브라우저의 **IndexedDB**에 저장되며, 구글 백업을 켜기 전에는
  기기를 벗어나지 않습니다.
- **계좌번호가 들어 있으니 PIN 잠금을 켜 두시길 권합니다.** (설정 → 보안)
  PIN은 PBKDF2(SHA-256, 21만 회) 해시만 저장하고 PIN 자체는 저장하지 않습니다.
  다만 이것은 남이 기기를 잠깐 만졌을 때 못 보게 하는 잠금이며, 저장된 데이터 자체를
  암호화하지는 않습니다. 기기 잠금화면 암호도 함께 켜 두세요.
- 팀원 상세에서 계좌는 뒤 4자리만 보이고, **복사**를 누르면 전체가 복사됩니다.
- **주의**: 브라우저에서 "사이트 데이터 삭제"를 하거나 앱을 지우면 데이터도 함께 지워집니다.
  가끔 백업 파일을 내보내 두세요.

## 사용법 요약

- 처음 쓸 때는 **현장 → ＋** 로 현장을, **팀원 → ＋** 로 팀원을 먼저 등록합니다.
- **일정 탭 → ＋ 배정**: 날짜와 현장을 고르고, 나갈 팀원을 켜면 그 사람 일당·공수·자차가
  펼쳐집니다. 여러 명을 한꺼번에 저장합니다.
- 이미 그 현장에 배정된 사람은 회색으로 `배정됨`, 그 날 다른 현장에 간 사람은
  그 현장 이름이 노랗게 표시됩니다.
- 출역 줄을 **탭**하면 수정, **길게 누르면** 삭제.
- 팀원 카드를 **탭**하면 상세(계좌·이번 달 출역·가불 내역), **길게 누르면** 바로 수정.
- **정산 탭**에서 달을 넘기며 확인하고, 오른쪽 위 📋로 요약을 복사해 문자로 보낼 수 있습니다.
  팀원 줄을 누르면 그 사람 것만 따로 복사할 수도 있습니다.
- 표 전체가 필요하면 **CSV로 내보내기**를 누르세요. 엑셀에서 바로 열립니다.

## 파일 구조

```
work/
├── index.html              앱 화면 (셸)
├── manifest.webmanifest    홈 화면 추가·앱 이름·아이콘 정의
├── sw.js                   서비스 워커: 오프라인 캐시
├── css/style.css           모바일 우선 스타일 (다크/라이트/하늘색)
├── icons/                  앱 아이콘
└── js/
    ├── app.js              화면 구성, 탭 이동, 설정, 잠금 화면
    ├── db.js               IndexedDB 저장소 (기기 내부 전용)
    ├── store.js            팀원·현장·출역·가불 도메인 로직과 월 정산 계산
    ├── editor.js           팀원·현장·배정·가불 입력 시트
    ├── sheets.js           구글 로그인과 스프레드시트 백업
    ├── lock.js             PIN 해시 설정·검증
    ├── ui.js               토스트, 바텀 시트, 확인창
    └── util.js             날짜·금액 유틸리티
```

라이브러리 없이 순수 HTML·CSS·JavaScript(ES 모듈)로만 만들었습니다.

## 직접 실행해 보기

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/work/ 접속
```

구글 백업까지 로컬에서 시험하려면, 구글 클라우드의 **승인된 자바스크립트 원본**에
`http://localhost:8000` 도 함께 추가하세요.
